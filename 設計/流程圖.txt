【前台頁面】
┌──────────────────────────┐
│ 首頁（中央：地圖區）       │
│ └─ 右上角：登入按鈕（後台） │
│ └─ 搜尋欄（選棟別/樓層/地點） │
│ └─ 地圖顯示區                 │
│      ├─ 室外：Google Maps + GPS
│      └─ 室內：SVG 地圖 + Wi-Fi 定位
│ └─ 導航起點 ➔ 終點路線規劃
└──────────────────────────┘

【登入後 ➔ 後台頁面】
┌──────────────────────────┐
│ 後台管理首頁               │
│ └─ 建築管理（新增/刪除建築）│
│ └─ 樓層管理（新增/刪除樓層）│
│ └─ 地圖上傳與預覽           │
│      └─ 上傳 SVG → 預覽 → 連結樓層
│ └─ 節點管理                 │
│      ├─ 點擊地圖新增節點
│      ├─ 自動/手動連接 neighbor
│      ├─ 自動轉角補節點（可手動）
│ └─ 路線導航設定              │
└──────────────────────────┘

【定位系統】
┌──────────────────────────┐
│ 定位偵測                   │
│ └─ GPS 定位（戶外模式）     │
│ └─ Wi-Fi 定位（室內模式）   │
│ └─ 依位置切換地圖模式       │
└──────────────────────────┘

【導航引擎】
┌──────────────────────────┐
│ 尋路系統                   │
│ └─ Dijkstra / A* 演算法     │
│ └─ 跨樓層節點處理           │
│ └─ 路徑繪製於地圖上         │
└──────────────────────────┘
